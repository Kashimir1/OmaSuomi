英語・日本語との比較： フィンランド語の語順は英語とほぼ同じです！

🇫🇮 Minä olen Susan = 🇬🇧 I am Susan = 🇯🇵 私はスーザンです

フィンランド語も英語も「主語→動詞→名前」の順番（SVO）。日本語は「主語→名前→動詞」（SOV）なので、英語の語順で考えた方がわかりやすいです。また、日本語と同じく「minä」（= I）を省略して「Olen Susan」とも言えます。

会話の続き

Susan: Minkä maalainen sinä olet?
あなたはどこの国の方ですか？
What nationality are you?
Juhani: Olen suomalainen.
フィンランド人です。/ I am Finnish.
Susan: Puhutko englantia?
英語を話しますか？ / Do you speak English?
Juhani: Joo, puhun.
はい、話します。/ Yes, I do.
Susan: Mutta nyt me puhumme suomea, me olemme Suomessa.
でも今はフィンランド語を話しましょう、フィンランドにいるんですから。
But now we speak Finnish, we are in Finland.
「Minkä maalainen sinä olet?」について： 直訳すると「何の国の人　あなたは　ですか？」。日本語の「どこの国の人ですか」に当たります。答え方：国名 + -lainen / -läinen（〜人）。例：suomalainen（フィンランド人）、japanilainen（日本人）。
「Puhutko」の構造： puhut（you speak）+ -ko（疑問を作る接尾辞）= Puhutko?（Do you speak?）

英語では「Do you speak?」のように助動詞 do を文頭に置く。フィンランド語では動詞に -ko/-kö をくっつける。日本語の「〜か？」に似ているが、文末ではなく動詞にくっつく点が違う。

フィンランド語の最も重要な文法のひとつ。動詞OLLA・ASUA・PUHUAの活用と、母音調和のルール。

人称変化とは？

英語を知っていればわかりやすい！ 英語でも "I am" / "you are" / "he is" と主語によって動詞が変わりますよね？フィンランド語も同じです。しかもフィンランド語はすべての動詞が人称変化します（英語では be 動詞と三人称-s だけ）。

日本語では「住む」はだれが主語でも「住む」のままなので、この感覚は英語で考えた方がわかりやすいです。

p.33 — ko/kö-kysymykset（はい/いいえ疑問文）

ko/kö 疑問文の作り方 — How to make yes/no questions

日本語の「～ですか？」に相当します。動詞に -ko（後舌母音 a, o, u の後）または -kö（前舌母音 ä, ö, y, e, i の後）をつけます。

In Japanese, this is like adding 「か」 to the end. In Finnish, add -ko/-kö to the verb and move it to the front.

Sinä puhut venäjää.（あなたはロシア語を話します）
→ Puhutko sinä venäjää?（あなたはロシア語を話しますか？）

He ymmärtävät englantia.（彼らは英語がわかります）
→ Ymmärtävätkö he englantia?（彼らは英語がわかりますか？）

母音の規則 — Vowel harmony rule:
a, o, u を含む動詞 → -ko（例: puhut → puhutko）
ä, ö, y, e, i のみの動詞 → -kö（例: ymmärrätte → ymmärrättekö）
日本語との比較：
日本語: 話します → 話しますか？（「か」を後ろに追加）
フィンランド語: Puhut → Puhutko?（「ko」を動詞につけて、文の先頭に移動）

英語: You speak → Do you speak?（Do を追加）
フィンランド語はDoのような助動詞は不要！動詞＋koだけ。

⚠️ puoli の罠 / The "puoli" trap:

フィンランド語の「半」は次の時間を基準にします！

puoli kolme = 2:30（3の半分の道 = 2:30）
puoli viisi = 4:30（5の半分の道 = 4:30）

分格の作り方 / How to form the partitive:

1. 母音で終わる語 → + a/ä

Verbityyppi 1: pukea ja tietää — 動詞タイプ1のKPT

動詞タイプ1でKPT交替がある動詞の復習。
不定形は強形、minä/sinä形は弱形になる。
pukea（着る）— k → ∅:
minä puenme puemme
sinä puette puette
hän pukeehe pukevat

tietää（知る）— t → d:
minä tiedänme tiedämme
sinä tiedätte tiedätte
hän tietäähe tietävät
他のKPT動詞タイプ1:

laittaa → laitan（tt→t）置く
antaa → annan（nt→nn）あげる
ottaa → otan（tt→t）取る
etsiä → etsin（KPTなし）探す
lähteä → lähden（t→d）出発する
ymmärtää → ymmärrän（rt→rr）理解する

注意： st, sk, tk の組合せは変化しない！
ostaa → ostan（変化なし！）
laskea → lasken（変化なし！）

lukea → minä ___ luen（k → ∅ 消える）

KPTルール — Astevaihtelu（子音交替）

フィンランド語で最も重要な音変化のルール。
子音 k、p、t が特定の条件で「弱くなる」現象。
日本語の連濁（れんだく）に似ているが、フィンランド語では子音が弱化・消失する。
基本原則 — Perusperiaate
開音節（母音で終わる）= 強形（vahva aste）
閉音節（子音で終わる）= 弱形（heikko aste）

音節が「閉じる」と、k/p/t が弱くなる。
例：kauppa（店）→ kaupan（-n を付けると pp → p）
交替パターン一覧 — Astevaihtelutaulukko
二重子音 → 単子音（重子音のパターン）
強 (vahva) 弱 (heikko) 例
kkk pankki → pankin
ppp kauppa → kaupan
ttt matto → maton
単子音の変化（覚えにくいパターン）
強 弱 例
k–（消える） lukea → luen
pv tapa → tavan
td katu → kadun
子音クラスターの変化（同化パターン）
強 弱 例
nkng Helsinki → Helsingin
mpmm kampa → kamman
ntnn ranta → rannan
ltll ilta → illan
rtrr parta → parran
動詞タイプとKPTの方向 — Verbityypit ja astevaihtelu
重要：動詞タイプによって交替の方向が逆になる！
タイプ1-2 = 不定形が強 → 活用形が弱（普通の方向）
タイプ3-4 = 不定形が弱 → 活用形が強（逆方向！）
タイプ1（-a/-ä）: 強 → 弱
不定形は強形。minä形で弱化する。
不定形（強） minä（弱） 変化
ottaa otan tt → t
lukea luen k → ∅
tappaa tapan pp → p
antaa annan nt → nn
ympärillä ymmärrän mp → mm
タイプ2（-da/-dä）: 変化なし
KPT交替が起こらないタイプ。
不定形 minä 備考
syödä syön KPTなし
juoda juon KPTなし
タイプ3（-lla/-nna/-rra/-sta）: 弱 → 強 ⚠️逆方向！
不定形が弱形。活用すると強くなる。
不定形（弱） minä（強） 変化
jutella juttelen t → tt
ommella ompelen mm → mp
nousta nousen （-sta特殊）
ajatella ajattelen t → tt
タイプ4（-Vta/-Vtä、母音+ta）: 弱 → 強 ⚠️逆方向！
不定形が弱形。活用すると強くなる。
不定形（弱） minä（強） 変化
pudota putoan d → t
tavata tapaan v → p
hypätä hyppään p → pp
pakata pakkaan k → kk
タイプ5（-ita/-itä）: ケースによる
短い語幹。KPTがある語とない語がある。
不定形 minä 備考
tarvita tarvitsen KPTなし
häiritä häiritsen KPTなし

jutella → juttelen の解説
jutella はタイプ3の動詞（-lla語尾）。

なぜ不定形が「弱」なのか？
ju-tel-la → 「tel」の音節が子音（l）で閉じている → 弱形（t）

なぜ活用形が「強」なのか？
jut-te-len → 「te」の音節が母音（e）で開いている → 強形（tt）

覚え方のコツ — Muistisääntö
1. 二重子音（kk, pp, tt）:
→ 単純に1つ減る。一番簡単！

2. 単子音（k, p, t）:
→ k は消える（一番トリッキー！）
→ p は v になる
→ t は d になる

3. クラスター（nk, mp, nt, lt, rt）:
→ 後ろの子音が前の子音に「吸収」される
→ nk→ng, mp→mm, nt→nn, lt→ll, rt→rr

4. 方向の覚え方：
→ タイプ1-2：辞書形が「重い」→ 活用で「軽く」なる
→ タイプ3-4：辞書形が「軽い」→ 活用で「重く」なる
KPTが起こらない場合 — Poikkeukset
以下の場合、KPT交替は起こらない：

1. 語頭のk/p/t（例：puhun — 語頭のpは変わらない）
2. 外来語の一部（例：bussi → bussin、KPTなし）
3. 3人称単数（hän）は多くの場合、強形を保つ
4. k/p/tの後にもう一つ子音がある場合（例：lasten — stは変わらない）
